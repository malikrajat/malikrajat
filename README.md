## About

Frontend architect and lead engineer with **15+ years** building large-scale web products for enterprise, energy, telecom and fintech teams — the last **6+ years at Siemens**, before that at **HCL** and **Siemens Energy**. I own the technical direction — architecture, performance, accessibility, testing and release quality — and stay hands-on in the code that delivers it.

I work across the full stack: frontend architecture with Angular, React and TypeScript, backend services with Node.js, and AI-native features built with Copilot and LLM APIs.

My work lands in three places: modernising legacy Angular and React platforms without stalling delivery, setting up design systems and micro-frontend boundaries so teams ship independently, and lifting Core Web Vitals on products where speed directly affects revenue.

> **Measurable outcomes**
>
> - Raised a production **Lighthouse score from 20 → 97** through rendering, bundle and asset-delivery optimisation.
> - Improved **Core Web Vitals (LCP, FID, CLS) by 80%**.
> - Led an energy-platform redesign delivering a **47% performance boost** and a **32% increase in customer acquisition**.
> - Cut **release-time bugs by 63%** and reached **90% unit-test coverage**.
> - Reduced **runtime bottlenecks by 48%** via memory-leak resolution and performance profiling.
> - Introduced **Backend-Driven Architecture**, cutting development effort by **13%**.
> - Led micro-frontend adoption, **reducing deployment overhead** and enabling independent releases.
